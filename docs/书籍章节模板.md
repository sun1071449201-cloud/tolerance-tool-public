# 章节内容模板（v1）

每个知识点章节按下面顺序写，读者先拿结论，再看推导和边界。

## 本章解决什么问题

一句话说明本章要解决的真实问题，不写“本章介绍……”。

## 先给结论（3 条以内）

- 结论 1：能直接指导选型/标注/检验。
- 结论 2：说明最重要的边界。
- 结论 3：说明最容易犯的错。

## 适用边界

- 适用的标准/版本/尺寸段/材料/工艺。
- 明确写出“不适用”的情况。
- 经验值必须标【经验值】，不能冒充标准值。

## 反例

一张图/一个场景：错误做法 → 后果 → 正确做法。
不要只写“要注意”，要让读者看到错在哪。

## 判断表 / 流程

能表格化就表格化；一张表只解决一个判断。

## 现场检查清单

- [ ] 图纸/基准/公差带是否一致
- [ ] 测量方法是否能复现
- [ ] 标准/客户规范版本
- [ ] 记录与追溯

## 自测（3 题）

每题 2~4 个选项，必须给答案和一句解释；答对 2/3 才算掌握。

## 版本

- 依据标准 + 版本年份
- 最后复核日期
- 新旧标准差异
