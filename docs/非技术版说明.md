# 非技术版说明（写给机械工程师）

> 本文档不谈代码架构，只谈：这个应用有什么功能、每个页面输入什么输出什么、哪些数值是占位待你核对的、以及 5 条验收测试用例。

## 1. 这是什么应用

一个**完全离线**的手机查询工具：查尺寸公差与配合、查形位公差、查名词解释；查询结果附带"为什么"（配合性质、默认公差原则、标准差异），让查表的过程同时是学习的过程。支持 ISO / GB / ASME / SS ISO 多标准，数值与知识提示随标准切换。

## 3. 页面清单与输入/输出

### 当前版本只有 1 个页面：尺寸公差与配合查询

**你输入什么：**
- 一行文本：基本尺寸 + 公差带代号，如 `⌀50 H7/g6`（也认 `50H7/g6`、`φ30 H7/k6`、`50 H7`）
- 或直接点击示例按钮（⌀50 H7/g6、⌀30 H7/k6、⌀50 H7/p6、⌀20 H8/f7、⌀50 H7）

**你得到什么（从上到下）：**
1. **查询结果标题**：配合代号、配合性质（间隙/过渡/过盈）、基孔制/基轴制、所在尺寸段（如 30~50）、当前标准（如 ISO_286）
2. **极限偏差表**：孔的上/下偏差（ES、EI）、轴的上/下偏差（es、ei），单位 mm，3 位小数带正负号
3. **配合结果**：最大间隙 Xmax / 最小间隙 Xmin（或最大/最小过盈）
4. **2D 公差带图**：零线 = 基本尺寸，孔公差带矩形（蓝色）、轴公差带矩形（第三色），向上为正偏差；两条双向箭头标出 Xmax / Xmin 区间，图下方有数值标签。深色/浅色模式自动配色
5. **知识提示卡**（每张卡底部注明出处，如 "knowledge_relations #9"）：
   - 当前标准默认公差原则（如 ISO 默认独立原则、ASME 默认包容要求）
   - 配合性质解释卡（间隙/过渡/过盈的定义 + 一条工程意义）
   - 基孔制说明卡、H7 名词卡（命中时）
6. **错误提示**（红色卡）：代号不合法、尺寸超范围、**数值未收录**——查不到就明说，绝不显示编造的数

### 后续版本页面（预告）

- 反选求解页：输入尺寸 + 配合类型 + 期望间隙/过盈范围 → 输出按匹配度排序的配合推荐列表，每条附推荐理由（可追溯到知识表记录）+ 加工成本提示
- 形位公差页：选项目（14 个符号）+ 等级 → 输出公差值；两个项目同时查看时自动校验（如"平行度公差带包含平面度公差带，当前平面度 0.05 > 平行度 0.03，标注形同虚设"）
- 名词词典页：全部术语/符号卡片，可搜索
- 设置页：标准切换（切换时弹出等价/差异提示）+ 数值核对进度

## 4. 哪些数值是占位、待你核对的

**全部标准数值都是占位**（应用界面有黄色警示横幅；数据库每行带 `verified=false` 和来源占位）。具体范围：

| 数据 | 范围 | 位置（JSON 文件） |
|---|---|---|
| 标准公差 IT 值 | IT5~IT12 × 13 个尺寸段（≤3 … 400~500 mm） | `assets/data/it_tolerance_values.json` |
| 轴基本偏差 | c/d/e/f/g/h/k/n/p（≤120 mm）、s（≤50 mm），定义侧偏差值 | `assets/data/fundamental_deviation_values.json` |
| 孔基本偏差 | H（EI=0，定义值，也请复核） | 同上 |
| 优先配合清单 | 11 组基孔制组合 + 用途说明 | `assets/data/preferred_fits.json` |
| 未注公差 | ISO 2768 / GB/T 1804 的 m、c 级线性值 | `assets/data/general_tolerances.json` |
| 知识提示文案 | 20+ 条关系与 8 张名词卡的文字 | `assets/data/knowledge_relations.json`、`explanation_cards.json` |

**超出以上范围一律明确提示"未收录"**（如 u 轴代号、>120 mm 的轴偏差、IT13 以上等级），不会编造。

**怎么替换**：直接编辑上面这些 JSON 文件，改数值、把该行 `verified` 改为 `true`、补上真实来源（如 "GB/T 1800.1-2020 表 1"）。重新打开应用即自动导入（数据校验通过才会入库）。后续版本会加"设置页 → 数值核对进度"显示还剩多少行待核对。

**注意**：本文档及测试用例中的"期望输出"是**当前占位数据集的计算结果**，不是标准答案；你核对替换 JSON 后，应用输出会自动随之更新。

## 6. 已知边界（v0.1 占位数据集）

- 轴偏差只收到 120 mm（s 只到 50 mm）、IT 等级只收到 IT5~IT12、孔代号只有 H——其余明确提示未收录
- ASME 尺寸数值未收录：选择 ASME 标准族时会回退显示 ISO 286 并明确提示"暂按 ISO 显示"
- 形位公差值表为空（里程碑 4 填充）；标准切换 UI 未做（里程碑 6）
