# 自定义知识导入格式模板

入口：**知识书籍 Tab → 右上角 ⬆ 导入自定义知识**。支持选择本地文件（JSON / CSV / Markdown / TXT）或直接粘贴文本。
导入成功的条目写入本地数据库（标记 `custom_import`），**自动进入"今日知识点"随机推荐池**，卡片显示来源标签"**我的笔记**"。

## 一、JSON 格式（推荐）

```json
[
  {
    "title": "沉头孔深度要控",
    "text": "沉头螺钉装配后头面平齐度影响滑动件运动，锪孔深度按螺钉头高 +0.1 试装确认。",
    "category": "结构避坑"
  },
  {
    "title": "铝件攻丝转速减半",
    "text": "铝件攻丝转速比钢减半并充分润滑，防止积屑瘤堵牙。",
    "category": "加工经验"
  }
]
```

字段说明：`title`（标题）与 `text`（正文）必填；`category`（分类）可选，缺省为"我的笔记"。正文兼容键名：`text` / `body` / `content` / `正文`。

## 二、CSV 格式

第一行为表头：`title,text,category`。含逗号的字段用英文双引号包裹（引号内两个 `""` 表示一个引号）。

```csv
title,text,category
薄壁件夹紧力,"径向夹紧必变形，改轴向压紧或真空吸盘",装夹经验
深孔钻退屑,"深径比大于 3 的孔每钻 1~2 倍直径退屑一次",加工经验
```

## 三、Markdown 格式

每个 `#`/`##` 标题 = 一条知识的标题，其后文字 = 正文，直到下一个标题。

```markdown
# 铰孔余量别过大

铰削余量过大反而扩孔拉毛，留 0.1~0.15 mm 即可（视孔径）。

# 深孔钻周期退屑

深孔钻每钻进 1~2 倍孔径退屑一次，防止铁屑堵死折断钻头。
```

## 四、注意事项

1. 单条正文建议 10~200 字，太长会在推荐卡片上被截断展示（详情可见全文）。
2. 导入是**追加**操作，不会覆盖系统知识与已有笔记；误导入的条目目前可通过再次导入覆盖或联系开发者清理。
3. 导入成功后立即进入当日之后的"今日知识点"抽取池；当天的 3 条已经抽出，不会回填当天。
4. 文件编码必须是 UTF-8。
