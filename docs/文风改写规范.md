# 书籍文风改写规范（v1，2026-10-25）

> 目标：把 5 本书从“AI 说明书”改成“老工程师带徒弟”的口吻。
> 底线：**技术事实、数值、标准号、图表结构一律不动；不编造数据、案例、出处。**

## 1. 一句话标准

读者应该觉得：**车间里干了三十年的老师傅，正指着图纸/零件，用大白话把这件事讲给你听。**

不是写散文，也不是讲段子。该硬的地方必须硬：数值、标准、公式、检验方法，一个都不能错。

## 2. 必须保留的结构（硬约束）

1. **所有标题行原样保留**：`#`、`##`、`###` 的层级和文字都不能改。锚点跳转依赖 `## 1.2 xxx` 里的节号，改一个字就可能跳错。
2. **代码块原样保留**：```mermaid ... ```、```sketch:xxx ... ```、```【简图】... ``` 的内容、顺序、语言标记都不能动。
3. **表格里的数值原样保留**：可以改写表头旁的说明文字，但不能改数值、单位、公差带代号、材料牌号、标准号。
4. **图片/简图占位原样保留**：`【xxx】` 简图块不要删、不要改名字。
5. **章节顺序、文件路径、manifest 不动**。
6. **不新增一级/二级/三级标题**。需要分层时用 **加粗小标题** 或列表，不要用 `###`。
7. **不删除“待核对”提示**。原文有 `【范围值待核对】`、`verified=false`、`source_ref` 之类，必须保留原意。

## 3. 可以怎么改

- 把“定义 + 术语堆叠”改成“先讲人话结论 → 再解释术语 → 再给车间场景”。
- 把一坨 300 字的长段落拆成：短段 + 列表 + 对照表。
- 第一次出现的专业词，先用一句大白话解释，再把术语亮出来。
- 每条规则尽量补一句“**什么时候别用**”或“**用错了会怎样**”，这是老师傅和说明书的区别。
- 适当用“你可以把它想成……”“车间里最怕的是……”“记住一句话……”这类口吻。
- 保留专业术语，但不要让术语打头阵。

## 4. 绝对不要做的事

1. **不编数值**：不改、不补、不“估算”任何尺寸、公差、温度、比例、寿命、价格。
2. **不编案例**：不写“某厂某零件因 0.03mm 报废”这类带具体数字的新故事。需要举例时，用“比如一根常见的 ⌀10 销轴”这种基于原文数据的通用例子。
3. **不编标准/出处**：不新增 GB/T、ISO、ASTM 编号；原文没有的标准号不要补。
4. **不把“待核对”写成“已核对”**。
5. **不写 AI 腔**：少用“首先/其次/最后/综上所述/值得注意的是/在实际应用中/极大地/赋能/闭环”等词。
6. **不为了生动而牺牲准确**：拿不准的工艺细节，保留原文说法，只把句子讲顺。
7. **不把技术内容改成鸡汤**：比喻是帮忙理解的，不能代替参数和判断依据。

## 5. 语气标尺

- 称呼：默认用“你”，像师傅对徒弟说话；需要正式时用“设计者/检验员”。
- 句子：短句为主，一段 3～6 行；手机上一屏能读完。
- 态度：直接、有经验、有边界感；不吓唬人，也不打包票。
- 比喻：来自车间和生活（通止规、卡尺、门框、鞋、香蕉轴、拧螺栓），不要用互联网/金融比喻。
- 频率：每个小节 1～2 个比喻足够，不要句句打比方。

## 6. 已确认的样稿（《综合知识手册》1.4）

**独立原则：各管各的，谁也不替谁兜底**

这是默认规矩，图纸上不用额外写符号。意思很直白：**尺寸管大小，形位管姿势，分开判。**

比如一根 ⌀10h6 的销，卡尺量直径在公差范围内，但整根销弯了 0.03——只要图纸没标直线度，按独立原则，检验员不能拿“弯”判它超差。听着有点不讲理？其实道理是：你没要求它直，它就没有“直”的合格线。就像买鞋只看脚长，脚背高不高、磨不磨脚，那是另一回事。

- **好处**：检验简单、成本低，能用卡尺、千分尺解决的，绝不往上加设备。
- **风险**：尺寸全合格、装配装不进，很多“扯皮官司”就是这么来的。
- **什么时候必须补形位公差**：怕弯的轴、怕歪的孔、怕翘的板。尺寸公差不会自动帮你管这些。

一句话：**独立原则最便宜，但它不兜底。**

**包容要求 Ⓔ：给零件套个“看不见的盒子”**

在尺寸后面加 Ⓔ，意思是：**光每个截面尺寸合格还不够，整根零件的实际轮廓不能超出最大实体边界。**

拿轴举例：⌀10h6 Ⓔ 的销，除了直径要在 9.991～10 之间，还得能从头到尾塞进一个 ⌀10 的“理想套筒”。弯了、鼓包了、中间粗了，塞不进去就不合格。孔则反过来：得能让一根和孔最小尺寸一样大的“理想塞规”通过去。

车间大白话：**“通规过得了，才算数。”**

## 7. 常用术语的“人话”对照（可复用，但别机械照抄）

| 术语 | 可以这样解释 |
|---|---|
| 公差 | 允许的误差范围，不是“做得越准越好” |
| 配合 | 孔和轴装在一起的松紧关系 |
| 间隙/过渡/过盈 | 能转 / 半紧 / 抱死 |
| 形位公差 | 管零件的“姿势”：正不正、直不直、歪不歪 |
| 基准 | 零件在夹具/检具上被“按住”的那个靠山 |
| 尺寸链 | 一环扣一环，最后那个尺寸是“算出来”的 |
| 独立原则 | 尺寸和形状各管各的，谁也不替谁兜底 |
| 包容要求 Ⓔ | 给零件套个盒子，通规过得了才算数 |
| 最大实体要求 Ⓜ | 孔做大了，位置可以松一点；只保装得上，不保定得准 |
| 表面粗糙度 | 表面“毛不毛”，影响密封、摩擦、疲劳 |
| 热处理 | 给材料“练筋骨”，改的是内部组织 |
| 阳极氧化 | 给铝件表面长一层氧化膜，不是刷漆 |
| 电解抛光 | 用电化学方法把表面“削平一层”，不是镀层 |
| 喷砂 | 用砂粒打出一个均匀的麻面 |
| 电镀 | 在表面“长”一层金属 |
| 钣金 | 把金属板当纸一样折、剪、冲 |
| 压铸 | 把金属液高速挤进模具，冷却后成形 |
| 焊接 | 把两块金属局部熔在一起 |
| DFM | 好不好造；DFA | 好不好装 |
| QC | 好不好检、判得准不准 |
